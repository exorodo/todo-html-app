## Why

Users need to add todos and see them in a list. This is the core interaction of the app.

## What Changes

- Add input field and Add button inside `#input-area`
- Add JavaScript: `todos` array, `addTodo()`, `renderTodos()` functions
- Style input and button elements
- Render `<li>` elements inside `#todo-list`

## Capabilities

### New Capabilities
- `todo-input`: Input field with Add button and Enter key support
- `todo-list-render`: Render todos array as list items in the DOM

### Modified Capabilities

## Impact

- Modifies `index.html`: adds HTML elements, CSS styles, and JavaScript logic
