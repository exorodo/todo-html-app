## todo-delete
### Requirements
1. Each `<li>` contains a `<button class="delete-btn">x</button>`
2. Delete button: right side, small, no border, transparent bg
3. On hover: red color
4. Click: removes todo from array by id, re-renders
### Scenarios
- Given a todo, When I click x, Then it disappears from the list
- Given the delete button, When hovering, Then it turns red
